# 🩺 RetinaCare – AI-Based Diabetic Retinopathy Detection System

## 📌 About the Project
RetinaCare is a web-based healthcare application designed to support the early detection and awareness of Diabetic Retinopathy. It allows users to upload retinal images and view assessment results through a simple and user-friendly interface.

The application aims to make diabetic eye health monitoring more accessible through technology.

## ✨ Features
- Upload retinal fundus images.
- Display diabetic retinopathy assessment results.
- Track previous assessment history.
- Visualize assessment history using charts.
- Multilingual user interface.
- Responsive design for mobile and desktop.
- Internet connectivity status indicator.

## 🛠️ Technologies Used
- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Icons:** Lucide React
- **Build Tool:** Vite

## 🚀 Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/likhithamadupu-netizen/Diabetic-Retinopathy-Detection-System.git
```

2. Navigate to the project directory:

```bash
cd Diabetic-Retinopathy-Detection-System
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
